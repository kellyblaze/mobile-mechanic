## New change request filed this checkpoint

### CR-008: issuing a quote doesn't change the service request's status

Read `packages/database/src/repositories.ts`'s `createQuoteJobRepository.createQuote` directly: it inserts into `quotes` and `quote_lines`, but never touches `service_requests.status`. A request stays `status = 'submitted'` forever, even after a quote has been issued against it — so `GET /admin/service-requests?status=submitted` keeps returning it, and the new `AdminIssueQuote` picker (built this checkpoint) can't tell an admin a request has already been quoted. Confirmed live, not just from reading the code: issued a real quote, then re-checked the picker immediately after — the just-quoted request was still listed. Disclosed with a visible in-app notice on `AdminIssueQuote` rather than silently hidden. Full detail in `docs/change-requests/CR-008.md`. Proposed fix is small: update `service_requests.status` (e.g. to `'quoted'`) inside the same transaction `createQuote` already runs.
